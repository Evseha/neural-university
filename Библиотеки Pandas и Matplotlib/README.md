Библиотеки Pandas и Matplotlib
Цель дать начальное представление об инструментах библиотеки pandas.
Способствовать формированию навыка загрузки, обработки и трансформации данных в таблицах pandas.

Навыки и инструменты:
numpy
matplotlib
random

Результат
Усвоил понятие таблицы pandas, научился читать данные из файлов, манипулировать значениями в ячейках, осуществлять срезы, отбор данных, определять пропуски и заполнять их, а также вычислять описательные статистики данных в таблице.
